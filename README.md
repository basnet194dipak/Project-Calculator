# Calculator

A simple calculator built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Live Preview

[View Live Demo](https://basnet194dipak.github.io/Project-Calculator/)

## Features

- Perform basic arithmetic operations:
    - Addition
    - Subtraction
    - Multiplication
    - Division
- Enter numbers using dynamically generated buttons.
- Display numbers, operators, and calculation results on the calculator screen.
- Perform consecutive calculations using the previous result.
- Round long decimal results to a reasonable precision.
- Display an error message when attempting to divide by zero.
- Clear the calculator to start a new calculation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites

A modern web browser is all you need. No additional dependencies or installations are required.

### Installation

1. Clone this repository:

    ```bash
    git clone https://github.com/basnet194dipak/Project-Calculator.git
    ```

2. Navigate to the project directory:

    ```bash
    cd YOUR_PROJECT_DIRECTORY
    ```

3. Open `index.html` in your preferred web browser.
